Installation de l'application et manuel de l'utilisateur

Vidéo de 4 minutes : Android, iPhone, ordinateur, puis rejoindre l'entreprise avec votre invitation.

1. Installer l'application

  1. Ouvrez le lien de l'application dans Google Chrome (bouton ci-dessous).
  2. Touchez les trois points en haut à droite, puis Installer l'application (ou Ajouter à l'écran d'accueil).
  3. Confirmez avec Installer : l'icône MG ERP apparaît parmi vos applications.
  4. Téléchargez le fichier d'invitation reçu : il va dans Téléchargements.
  1. Ouvrez le lien de l'application dans Safari (pas dans WhatsApp ni dans un autre navigateur).
  2. Touchez Partager (le carré avec une flèche vers le haut), faites défiler, puis Sur l'écran d'accueil.
  3. Touchez Ajouter : l'icône MG ERP apparaît sur l'écran d'accueil.
  4. Dans WhatsApp, ouvrez le fichier d'invitation, puis Partager › Enregistrer dans Fichiers.
  1. Ouvrez le lien de l'application dans Chrome ou Edge, sous Windows ou Mac.
  2. Cliquez sur l'icône d'installation à droite de la barre d'adresse (un écran avec une flèche), ou passez par le menu.
  3. Cliquez sur Installer : l'application s'ouvre dans sa propre fenêtre, avec une icône sur le bureau.
  4. Enregistrez le fichier d'invitation reçu par e-mail ou WhatsApp.
Ouvrir l'application

2. Rejoindre l'entreprise

  1. Ouvrez MG ERP depuis son icône et choisissez Rejoindre (collaborateur).
  2. Touchez Choisir le fichier d'invitation et sélectionnez le fichier reçu.
  3. Saisissez le code entreprise et le PIN provisoire donnés par le gérant, puis choisissez votre propre PIN (6 chiffres ou plus).
  4. Vos données arrivent d'elles-mêmes : il n'y a rien d'autre à configurer.
Ne choisissez jamais « Créer l'entreprise » si vous êtes collaborateur : vous créeriez une société séparée. Le code entreprise et le PIN ne s'envoient jamais par message.
